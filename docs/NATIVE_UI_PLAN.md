# Native UI Plan — abgelöste Historie

> Abgelöst am 2026-09-21 durch `../NIWOE_IMPLEMENTATION_PLAN.md`.

Die Entscheidung für native Rust-Oberflächen, zentrale Tokens, eine
unprivilegierte Shell und effiziente, eventgetriebene Darstellung bleibt als
technische Schutzregel bestehen. Die frühere Meridian-/BSD-Phasenfolge ist
jedoch nicht mehr aktiv. Für Reihenfolge, Designpräzisierung und Abnahme gilt
der NIWOE-Plan.
