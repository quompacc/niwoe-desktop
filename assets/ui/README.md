# Context landscape

`niwoe-context-landscape-v1.png` is a static 2172×724 header asset generated
with the built-in `image_gen` tool on 2026-10-02 for repair packages R2/R5/R6.
SHA-256: `05209cabf5196725f2a58bd1659e025bc393e924ad235b304857474f8535baa5`.
It is independent of the selected desktop wallpaper. Text, controls and icons
are drawn natively using the existing tokens/config; none are baked into it.

Final generation prompt:

> Use case: stylized-concept. Asset type: static landscape header artwork for
> the NIWOE native desktop Hub and Control Center, matching their binding dark
> green mountain mockups. Create one panoramic landscape, wide 3:1 composition.
> Dark desaturated forest-green alpine mountain ridges and layered mist in a
> calm cinematic photographic illustration. The left third is quiet very dark
> green atmospheric sky/mist with usable negative space for off-white UI headings
> rendered later; no text baked into artwork. The central-right sky has a
> restrained softly glowing ivory-gold eclipse ring above an imposing mountain
> peak, subdued gold dawn rim light, softer distant ridges. Low saturation, deep
> emerald/olive shadows, detailed but restful, ample dark sky across top and
> layered ridges in lower half. Intended as a shallow cropped header; keep the
> eclipse and main peak around the center-right and avoid high contrast texture
> on the left. No UI, no lettering, no logo, no compass, no icons, no borders,
> no watermark.

The selected output was inspected before copying into the project. Original
wallpaper assets are retained. Cache, crop and invalidation details belong to
the consuming repair report; generation alone is not a visual acceptance.
