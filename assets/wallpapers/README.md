# Alpine Dawn

`niwoe-alpine-dawn.png`: generated with the built-in image_gen tool on
2026-09-23, copied into the project and selected on the Fedora test desktop
at the user's request. No UI, branding or text is baked into the wallpaper.
Cloud structure reaches the top edge so panel transparency/blur can be judged.

Final generation prompt:

> Create one production desktop wallpaper, landscape 16:9, ideally 2560x1440.
> Stylized cinematic natural landscape: dark desaturated forest-green mountain
> ridges, layered rocky silhouettes and a quiet lake, soft warm ivory/gold dawn
> light in textured clouds. NIWOE desktop visual direction: near-black greens,
> muted olive, restrained warm gold. Detailed but calm, no oversaturation.
> Essential for judging translucent glass desktop UI: preserve visible
> medium-scale cloud contours and alternating light/dark structure ALL THE WAY
> to the TOP EDGE (a 48px top panel will overlay this), also on the upper right.
> Do not leave the top as an empty flat gradient. Mountains should have crisp
> silhouettes, distant ridges soft with atmospheric depth, subtle water
> reflections. No text, no logos, no compass, no border, no UI, no icons,
> no mockup frame. Deliver only the wallpaper artwork.
